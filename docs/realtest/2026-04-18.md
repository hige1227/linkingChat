## C. 发现的 Bug

### Bug 1: Logout 不清 Zustand Stores [严重]

**现象**: Desktop 登录 ice → 退出 → 登录 frank, UI 仍显示 ice 的会话列表, 403 Forbidden 错误
**原因**: `auth.ipc.ts` logout 只清了 `AuthStore.clear()`, 没有清 `chatStore` / `friendsStore` / `aiStore`
**修复方案**: logout 时 reset 所有 Zustand stores

### Bug 2: 消息/Bot 重复渲染 [中等]

**现象**: 聊天区出现两条 Jarvis 消息, Whisper 建议条也显示两条
**原因**: 可能是流式回复完成后 `addMessage` 被调用两次 (持久化 + WS push), 或 React re-render 导致
**影响**: Whisper 功能正常工作, 但 UI 显示重复

### Bug 3: Hermes fcntl 模块缺失 [轻微]

**现象**: `WARNING model_tools: Could not import tool module tools.memory_tool: No module named 'fcntl'`
**原因**: `fcntl` 是 Unix 专用模块, Windows 不存在
**影响**: memory_tool 不可用, 不影响核心功能
