## 一、测试背景

OpenClaw 的 `exec` 工具在 Windows 中文系统上输出中文文件名时乱码。历经两轮修复，本轮为最终修复后的验证。

## 二、修复过程

### 2.1 第一轮修复（失败）

在 `handleStdout` / `handleStderr` 中添加 `decodeWinBuffer`（基于 `chcp` 动态检测代码页）。

**结果**: 中文文件名显示为菱形方块（U+FFFD replacement character）。

**原因**: `createChildAdapter` 层的 `chunk.toString()` 在上游已将 GBK Buffer 损坏为 UTF-8 字符串，`decodeWinBuffer` 收到的是已损坏的 string 而非 Buffer，无法还原。

### 2.2 第二轮修复（成功）

两处修改：

1. **`createChildAdapter`（~L740-749）**: 去掉 `chunk.toString()`，透传 raw Buffer
2. **`decodeWinBuffer`（~L1548）**: 去掉 `chcp` 动态检测，硬编码 `new TextDecoder("gbk")`

## 三、验证结果

### 3.1 测试步骤

1. 修改 `%APPDATA%\npm\node_modules\openclaw\dist\model-runtime-D4KJqIwp.js`
2. 终止 Gateway 进程 (`taskkill //PID <pid> //T //F`)
3. Desktop App 自动重连，spawn 新 Gateway（确认 PID 变化）
4. Bot DM 中发送："列出桌面文件" / "dir C:\Users\87783\Desktop"

### 3.2 修复前（第二轮修复前，第一轮失败后的输出）

```
| context engnerring ָ` | 5.91 MB | 2025/12/24 |
| myinstall.docx | 31 KB | 2026/3/7 |
| Ź` | 124 KB | 2026/4/11 |
| ָ` | 1.16 MB | 2025/11/28 |
```

说明：GBK 字节被 UTF-8 解码，`D6 B8`（"指"）→ `ָ`（U+05B8 Hebrew point），其余字符产生 replacement character。

### 3.3 修复后（第二轮修复成功）

中文文件名正确显示，表格格式正常。

## 四、关键诊断方法

### 4.1 确认 Gateway 加载了新代码

```powershell
# 检查 Gateway PID
Get-CimInstance Win32_Process -Filter "Name='node.exe'" |
  Select-Object ProcessId,CommandLine |
  Where-Object { $_.CommandLine -match 'openclaw' }
```

kill 后等 3 秒再检查，确认 PID 变了。

### 4.2 本地验证 GBK 解码

```javascript
const decoder = new TextDecoder('gbk');
const buf = Buffer.from([0xD6, 0xB8, 0xC4, 0xCF]); // "指南" 的 GBK 编码
console.log(decoder.decode(buf)); // 应输出 "指南"
console.log(buf.toString());      // 输出 "ָ��" (UTF-8 误解码)
```

### 4.3 确认 chcp 代码页

```bash
node -e "const r=require('child_process').spawnSync('cmd.exe',['/d','/s','/c','chcp'],{windowsHide:true,encoding:'utf8',stdio:['ignore','pipe','pipe']}); console.log(r.stdout)"
# 输出: "活动代码页: 936"
```

## 六、注意事项

- 每次 `npm update -g openclaw` 会覆盖修改，需重新 patch
- 非中文 Windows 系统（日文 Big5/Shift_JIS 等）需对应修改编码名
- 代码页 65001 (UTF-8) 的 Windows 系统不需要此 patch
- 详见 `docs/rush/openclaw-win-gbk-encoding-fix.md`
