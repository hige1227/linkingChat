## 1. 战略愿景 (Vision)

打造**零门槛的贾维斯社交 App**。界面抄微信（所有人都会用），但每一次社交互动都有 AI 在背后帮你——帮你想回复、帮你措辞、帮你变得更有情商。

**核心理念：** 这不是一个 AI 工具 app（没人会主动打开 AI app），这是一个人人每天都在用的**聊天 app**，里面恰好住着一个贾维斯。用户打开它是为了和朋友聊天，AI 是自然融入的体验增量。

**与旧版本的关键区别 (v2.0 → v3.0)：**

| 维度 | v2.0 (旧) | v3.0 (新) |
|------|----------|----------|
| 产品本质 | 远程控制工具 + 聊天 | AI-native 微信 + 贾维斯 |
| 核心用户 | 工程师/技术团队 | **所有人** |
| 差异化 | 手机控制电脑 | AI 帮你高效高情商社交 |
| 移动端定位 | 远程遥控器 | **第一界面**（大部分人在手机聊天）|
| Whisper 优先级 | P1（用户主动触发） | **P0（自动触发，AI-native 灵魂）** |
| 多 Bot 策略 | MVP 就上 Supervisor + Coding Bot | MVP 只做一个贾维斯，做到极致 |

## 2. 核心痛点与解决方案 (Problem & Solution)

| 当前痛点 | LinkingChat 解决方案 |
| :--- | :--- |
| **社交低效** | 每天要回上百条消息，很多是重复性的客套、确认、约时间。脑力消耗大。 | **Whisper（耳语建议）：** 收到消息时，贾维斯自动建议 1 个最优回复 + 2 个备选。用户编辑/直接发送，省时省力。 |
| **措辞焦虑** | 给领导/客户/暧昧对象回消息时，反复措辞、怕说错话。 | **Draft & Verify（代理草稿）：** 告诉贾维斯你想表达什么，它帮你生成得体、高情商的措辞。你确认后再发送。 |
| **AI 恐惧感** | 害怕 AI 自动回复说错话，或自动操作删错文件。 | **草稿即正义：** 贾维斯永远只生成”草稿”或”建议”，必须由用户点击发送或确认。AI 不会自作主张。 |
| **工具割裂** | 需要”一边在 IM 聊需求，一边切到终端跑代码”。 | **远程执行：** 对贾维斯说自然语言，Bot 在你的电脑后台执行，结果回传到聊天窗口。 |

## 3. 三大核心交互模式 (The “Holy Trinity” Experience)

这是本项目区别于传统 IM 和传统 AI 工具的关键体验增量。**优先级已重排（v3.0）：Whisper 升为 P0，因为它是”AI-native 社交”的灵魂。**

### 3.1 交互 A: 耳语建议 (The Whisper) — **P0, AI-native 的灵魂**
* **场景：** 用户收到任何好友消息（如”今晚约饭吗？”）。
* **行为：** 贾维斯**自动**在输入框下方显示 **1 个最优回复** + 可展开 2 个备选。用户不需要 @ai 或点按钮——贾维斯就在那里，安静地等着帮忙。
* **关键：** 这不是弹窗，不是打断。是一条安静的建议，用户可以用也可以忽略。但它的存在让用户感受到”这个 app 里住着一个 AI”。
* **用户动作：** 直接编辑/发送建议内容，或展开备选替换，或完全忽略自己打字。
* **v2+ 演进：** 灰体补全（Ghost Text）——输入框获焦 + 停顿 ≥2 秒时，基于本地小模型意图预测自动显示灰体建议。

### 3.2 交互 B: 代理草稿 (Draft & Verify) — **P0**
* **场景：** 用户对贾维斯说”帮我回复张总，说周五开会没问题”或”把电脑桌面的 Q3 财报发给王总”。
* **行为：** 贾维斯**不自动发送**。它生成一段得体、高情商的回复文案（或连接电脑读取文件），将”文案 + 附件”作为草稿展示。
* **用户动作：** 用户确认无误后，点击 **[发送]**。

### 3.3 交互 C: 预测执行 (Predictive Actions) — **P1**
* **场景：** Bot 执行完一个任务后（如分析报错日志）。
* **行为：** Bot 自动预判用户的下一步需求，生成 **”下一步行动按钮”**（如 `[点击运行修复命令]`）。
* **用户动作：** 点击按钮，Bot 直接调用本地 Shell 执行。

## 4. 技术架构策略 (Technical Strategy)

采用 **"Cloud Brain + Local Hands" (云端大脑 + 本地傀儡)** 架构：

1.  **桌面端 (The Hand):**
    * **极简 Node.js Runtime:** 不安装完整的 OpenClaw/Python 开发环境。
    * **功能:** 仅作为一个 Socket 客户端，接收云端下发的 JSON 指令（如 `fs.readFile`, `child_process.exec`）。
    * **优势:** 实现“下载即用”，无环境依赖。

2.  **云端 (The Brain):**
    * **SaaS Core:** 托管所有 LLM 推理、Context 管理、User Prompt (`Soul.md`)。
    * **OpenClaw Logic:** 将复杂的 Agent 逻辑（工具调用、规划）封装在云端。

3.  **移动端 (The Primary Interface):**
    * **Flutter 原生 App:** iOS & Android from one codebase. 这是大部分用户的主界面。
    * **设计方向：** 微信/WhatsApp 风格，zero learning curve。Bot 作为固定置顶的系统级联系人——这就是你的贾维斯。
    * **AI 存在感：** Whisper 建议在每个对话中自然出现。用户打开 app 的第一秒就能感受到 AI。

## 5. 成功指标 (Success Metrics)

* **北极星指标 (North Star):** **Whisper 采纳率 (Whisper Accept Rate)**
    * 定义：贾维斯的回复建议被用户实际采纳（编辑后发送或直接发送）的比例。这直接衡量 AI-native 社交的核心价值。
* **体验指标 1:** **Draft-to-Send Rate (草稿发送率)**
    * 定义：贾维斯生成的草稿被用户实际采纳（点击发送）的比例。
* **体验指标 2:** **Daily Active Conversations with AI Assistance**
    * 定义：每日有多少对话中用户使用了 Whisper 或 Draft 功能。衡量 AI 渗透率。
* **基础指标:** **每日跨设备指令数 (Daily Cross-Device Intents)**
    * 定义：用户用手机指挥电脑执行任务的次数。远程控制能力的衡量。
